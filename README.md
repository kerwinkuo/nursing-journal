# 每日照護點選紀錄

這是一個給照護者使用的手機點選式紀錄頁面。開啟 `index.html` 後，用按鈕記錄失智症患者每天的心情、行為、黃昏症候群、譫妄警訊、身體狀況與安撫方式。

現在也支援 Supabase 雲端資料庫同步。預設仍會先存在目前瀏覽器裡，按「上傳雲端」才會把紀錄送到你的 Supabase 專案。

## 使用方式

1. 用手機或電腦瀏覽器開啟 `index.html`。
2. 選日期，或直接點「今天」。
3. 點選符合當天狀況的按鈕。
4. 點「儲存今天」。
5. 需要給醫師看時，點「匯出 CSV」。

## 手機使用

- 直接用手機瀏覽器打開 `index.html` 可以使用本機紀錄。
- 若要像 App 一樣加入手機主畫面，建議把整個資料夾部署到 HTTPS 網站，例如 GitHub Pages、Netlify、Vercel 或自己的網站。
- 部署後用手機開啟網址，再用瀏覽器功能選「加入主畫面」。

## Supabase 雲端同步

1. 建立 Supabase 專案。
2. 到 Supabase 的 SQL Editor 執行 `supabase_schema.sql`。
3. 到 Project Settings 找到 Project URL 和 anon public key。
4. 回到 app 的「雲端同步」區塊，填入 Project URL、anon public key、Email、密碼。
5. 第一次使用點「建立帳號」，之後點「登入」。
6. 點「上傳雲端」把本機紀錄同步到資料庫。
7. 換手機或換瀏覽器時，登入後點「下載雲端」即可合併回本機。

## 注意事項

- 紀錄存在目前使用的瀏覽器裡。換手機、換瀏覽器或清除瀏覽資料後，原紀錄可能不會出現。
- 雲端同步會傳送健康照護資料到你的 Supabase 專案，請使用可信任的帳號與密碼，並保留 SQL 裡的 RLS 權限設定。
- 「複製摘要」可快速貼到 LINE、簡訊或備忘錄。
- 若出現突然混亂、嗜睡叫不醒、跌倒後意識改變、呼吸困難、高燒，請盡快聯絡醫師或就醫。
- 這份工具是照護紀錄，不取代醫師診斷。
